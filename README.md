Premium Features

 Full-screen animated preloader using the Xeno Craft logo, where the green gradient logo is drawn smoothly before the homepage fades in.

 Custom animated cursor with a subtle green glow and magnetic interactions on buttons.

 Glassmorphism navigation with a premium blur effect.

 Scroll progress indicator using the Xeno Craft green gradient.

 Interactive 3D merchandise showcase with floating T-shirts, jerseys, caps, stickers, mugs, and welcome kits.

 AI-inspired product configurator with live color, size, and print preview.

 Infinite marquee of client brands and featured products.

 Animated statistics counters and timeline.

 Smooth page transitions with cinematic fade effects.

 Floating WhatsApp and "Get Quote" CTA buttons.

 Premium micro-interactions across every button, card, and image.

 Dark luxury aesthetic with soft green ambient lighting inspired by the logo.

 Architecture ready for future e-commerce, CMS, payment gateway, order tracking, and customer dashboard integration.

Final Vision

The website should look like it belongs on Awwwards—a premium, cinematic, dark-mode experience with sophisticated animations, exceptional typography, refined spacing, and immersive interactions. Every page should reinforce Xeno Craft as a high-end custom merchandise brand, using the exact green gradient from the logo as the only accent color while maintaining a luxurious black and charcoal visual identity. The result should feel world-class, memorable, and production-ready rather than template-based.
